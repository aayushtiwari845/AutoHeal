    AUTOHEAL STUDIO
    From error to evidence.
    The model writes Python. A subprocess executes it. The evaluator checks the output. When an attempt fails, structured feedback informs the next repair.
    1. GenerateProduce or repair executable Python.
    2. ExecuteCapture stdout, stderr, exit code, and duration.
    3. EvaluateCheck returned JSON against the task requirements.
    4. ReflectFeed error type, line, output, and failed checks back into the loop.
    Live model and scripted replay
    Live mode makes real Ollama calls. Scripted replay runs fixed, auditable programs to demonstrate the same execution and validation loop; it does not call an AI model.
    Execution constraints
    Generated code is checked and runs with a timeout of at most five seconds. File and network access are disallowed by application-level restrictions. These controls are not a hardened operating-system sandbox.
    The seeded fault is an explicit demonstration setting. Its use is recorded in the run trace.
