    About AutoHeal Studio

    Code execution with an observable repair loop.

    Generate Python, execute it, check the result, and use structured failure evidence to repair the next candidate. At most five attempts run.

    Two ways to inspect the same loop

    Automatic advances until the result passes or the limit is reached. Step through pauses between stages for inspection. Captured line replay shows recorded execution events, not a live debugger.

    Honest demonstration modes

    Live Ollama and configured API modes make model calls. Scripted replay executes fixed programs and makes no AI calls. The optional controlled first attempt is explicitly prewritten.

    Execution controls & limitations

    Python executes in a constrained subprocess with a maximum five-second execution timeout, output limits, and checks that disallow file and network access.

    These are application-level restrictions, not a hardened operating-system sandbox. Use the workbench for trusted local laboratory demonstrations.
